## Local JSON schema

The envelope uses `application: "engent-labs-forecasting-coach"` and `version: 1`. It includes `data` (or null for a draft without data), `settings`, `goal`, `units`, and `communication`. The data bundle includes the source name, selected worksheet name, selected time/target headings, and up to 5,000 date-or-period/value pairs. The saved project contains the active source series, not all workbook sheets, charts, formulas or unmapped columns. Dates use ISO calendar dates. Settings preserve the approach, forecast frequency, aggregation, window mode and choice, and per-approach horizons. Version 1 reads `decisionReflection` as a fallback when `communication` is absent.

Open validates the envelope and limits before replacing the current work, reconstructs the source series and recalculates when settings permit. JSON is limited to 2 MB. Project Save downloads a copy. Excel Upload continues to read data, and Excel Export continues to download forecast results plus the communication reflection.
