## Server contract

`server/shared/paid-ai-master.mjs` exports `createPaidAiMasterGate({readState,timeoutMs=2000}).assertEnabled()`. An adapter must perform a FRESH strongly consistent exact-key read, projecting pk/sk/suspended/revision, forwarding the abort signal. Only a plain record with `suspended:false` and a positive safe-integer revision permits continuation. OFF, absent/malformed values, unavailable configuration, read errors and timeout deny. The generic deadline is2seconds (maximum configurable10seconds); no ON decision is cached. A read late after timeout cannot dispatch a provider. Revision1 already exists in the current Alpha record; no data migration or toggle is proposed.

Every paid provider dispatch, including repairs/retries, must independently call the guard immediately before transport. The guard is an additional AND condition: identity/session, Coach-specific entitlement, local readiness/pause, own credential, budget reservation, rate/concurrency controls and timeouts still apply. An ON record grants no permissions and resets no spend. Master OFF blocks dispatch checks that observe OFF; a previously authorized send or already-dispatched provider operation cannot be recalled, and the DynamoDB read plus external HTTP send cannot be made atomic; no claim of retroactive cancellation is made. All provider libraries must avoid hidden retries that bypass the check.
