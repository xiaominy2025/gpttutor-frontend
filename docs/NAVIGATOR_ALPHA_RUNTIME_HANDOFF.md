## Browser contract

- On first submit, send a same-origin POST to /api/platform/navigator/session. An empty body or an empty JSON object is sufficient. A 200 reply contains {"ready":true}. A valid Navigator cookie is reused; otherwise the response sets a signed, one-day Secure, HttpOnly, SameSite=Strict, host-only cookie. The frontend never reads it. Allow this bootstrap to complete before making the first turn request.
- Send a same-origin JSON POST to /api/platform/navigator with message, history, optional continuation and optional dimension, identical to the draft protocol. Render reply and followUps. Keep continuation in memory. done is true on the fourth reply; continuation is then null. If the anonymous cookie expires or is replaced, the old conversation cannot be resumed. Do not silently replay a turn or reset the quota.
- Both POSTs require the exact Alpha Explore Origin. API Gateway supplies the source IP. All callers pass through the Guest controls, including visitors carrying a Release B session cookie. No account, entitlement, project, or transcript record is created. Operational state consists of hashed pseudonymous actors/IPs, budget, concurrency, and replay hashes with TTL. Do not add telemetry containing bodies, cookies, or decision text.
- Existing limits apply: two requests per minute and five per day per anonymous actor, one concurrent request per actor, 20 per IP per day, two globally concurrent requests, and a $10 UTC-month model ledger. A full four-turn run can span two minute buckets. Master denial after admission settles zero model spend and still counts against the request quota.
- The canonical master gate reads AI#CONFIG / STATE strongly consistently immediately before each provider dispatch. OFF, absent, invalid, slow, and failed reads deny dispatch. A request already sent to the model cannot be recalled. The adapter has no provider retry and pays only through the dedicated Standard GPT-6 Luna credential. Budget accounting conservatively charges all input tokens at the published $0.125/M cache-write rate and output at $0.50/M. Unknown provider outcomes retain the reserved amount. A signed turn remains consumed after provider dispatch is attempted, including when usage, parsing, or accounting fails. Deterministic pre-dispatch denials release the replay claim.
